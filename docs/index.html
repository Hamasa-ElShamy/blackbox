BlackBox

Guess an unknown file

Got a binary data file and no documentation? BlackBox guesses the header, record size and field types, colours a map of every byte, and writes a Python reader. It runs in your browser and nothing is uploaded.

Pick a sample. The first run downloads the Python engine (about 10 MB).

The generated reader



These are guesses from patterns, not knowledge of the format. Check a few rows against the real thing. Compressed, encrypted and variable-length files are not supported.


How it works


It tries record sizes and header sizes and scores how regular each byte column is. Then it walks across one record and tries: text, Unix time, decimal numbers, whole numbers 1, 2 or 4 bytes wide, in both byte orders. No AI, only rules, so every guess has a reason you can read in the code.


Honest limits


    

  • On 60 random layouts I built (random fields, ground truth known): header and record size exactly right in 53 of 60 files (30 before the rewrite; I looked at some misses while designing, so this is not a clean held-out set), but fields exactly right only 44% (46% before). On 6 more realistic layouts I made: layout 29 of 30, fields 50%. Signed numbers are not detected yet. The test is harsh on purpose (fully random numbers). Real files can do better or worse.
    • 

  • Small whole numbers can show up wider than they are, signed and unsigned are not told apart, and a timestamp can be mistaken for a decimal number (and the reverse).
    • 

  • A header whose size is a multiple of the record size can be read as a few extra records.
    • 

  • Fixed-size records only. No pointers, no variable-length fields, no bit fields.
    • 

  • Known formats (PNG, ZIP and others) are recognised and sent to a proper tool.
